# Barbearia Simão

Site institucional responsivo, catálogo de preços e página própria de links para a bio do Instagram.

## Estrutura

- `index.html`: página principal
- `links.html`: página de links da bio
- `servicos.html`: tabela interativa de serviços e preços
- `style/`: folhas de estilo
- `js/`: comportamentos JavaScript
- `img/profissionais/`: fotos da equipe
- `img/instagram/`: publicações usadas na galeria
